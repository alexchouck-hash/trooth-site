1. MCP Server Setup

Install Trooth as a single MCP server. Compatible with all clients supporting the Model Context Protocol.

Claude Desktop Configuration

Add Trooth to your claude_desktop_config.json: 

{
  "mcpServers": {
    "trooth": {
      "command": "npx",
      "args": ["-y", "@trooth/mcp-server"]
    }
  }
}

Cursor / Generic Agent Configuration

Add to your Cursor MCP settings or command-line agent launcher: 

# Run locally over stdio
npx -y @trooth/mcp-server

# Or connect to the edge HTTP endpoint
https://api.trooth.io/mcp

Available Tools

Trooth registers exactly six tools into your agent's context (CLAUDE.md Rule H10):

Tool Name Parameters Purpose
trooth.resolve query: string, domain?: string Resolve query to candidate sources with acceptance/rejection reasons. No fetch.
trooth.fetch request_id: string, freshness?: "live" | "cached_ok" | "as_of" Fetch verified payload wrapped in signed provenance envelope.
trooth.compare query: string, sources: string[] Query multiple sources simultaneously, returning field disagreements.
trooth.scorecard source_id: string Retrieve 6-dimension scorecard + anchored accuracy for a source.
trooth.catalog.search domain?: string, license?: string Search catalog feeds by domain, license, or refresh cadence.
trooth.verify envelope: object Verify Ed25519 signature and SHA-256 payload digest.

2. REST API Reference

Base URL: https://api.trooth.io/v1 (Local development: http://localhost:8787)

POST /resolve

Resolves a natural query to prospective sources without executing a network fetch. 

curl -X POST https://api.trooth.io/v1/resolve \
  -H "Content-Type: application/json" \
  -d '{ "query": "current weather at JFK airport" }'
POST /fetch

Fetches data from the resolved source and returns the complete signed provenance envelope. 

curl -X POST https://api.trooth.io/v1/fetch \
  -H "Content-Type: application/json" \
  -d '{
    "source_id": "nws",
    "endpoint": "latest_observations",
    "freshness": "live"
  }'
POST /verify

Cryptographically validates an envelope using the Trooth Ed25519 public key. 

curl -X POST https://api.trooth.io/v1/verify \
  -H "Content-Type: application/json" \
  -d @envelope.json

Verifying Signatures in Python

You do not have to trust Trooth blindly. Every envelope can be independently verified locally using standard cryptography libraries: 

import hashlib
from nacl.signing import VerifyKey

def verify_trooth_envelope(envelope, public_key_hex):
    # 1. Verify content hash
    expected_hash = "sha256:" + hashlib.sha256(
        json.dumps(envelope["data"], sort_keys=True).encode()
    ).hexdigest()
    assert envelope["provenance"]["sources"][0]["content_hash"] == expected_hash

    # 2. Verify Ed25519 signature
    vk = VerifyKey(bytes.fromhex(public_key_hex))
    sig_bytes = bytes.fromhex(envelope["signature"]["sig"])
    # Signature covers request_id + snapshot_id + content_hash
    signed_payload = f"{envelope['request_id']}:{envelope['provenance']['snapshot_id']}:{expected_hash}"
    vk.verify(signed_payload.encode(), sig_bytes)
    print("Envelope verified!")
