Scoring Methodology

Published by Modafied

Trooth does not score the sources it routes to, so the method that produces every grade on this site is not ours. It belongs to Modafied, it is public, and it is versioned independently of anything we ship.

Why the method is not ours

We sell the pipe these feeds travel through. A method written by the company selling you the pipe is discounted by any serious reader, so writing one was worth less than not writing one.

Modafied also does its own collecting, which matters more than it sounds. Freshness lag is the grader's clock minus the source's own event timestamp, so a grader working from somebody else's archive measures that supplier's scheduler rather than the source. An independent grade requires independent fetching, not just independent arithmetic.

The six dimensions

Shared vocabulary between the two projects. The definitions are here so the words on our pages mean something; the measurements, the thresholds, and the band table are Modafied's.

Freshness lag

How stale a value is when it is captured: the grader's clock minus the timestamp the source itself asserts. Reported as p50 and p95, because the tail is what breaks things.

Revision behaviour

How often a value already published for a fixed event time is changed afterwards. A high rate is a caching risk, not necessarily a fault: a source that revises may simply be careful.

Correction latency

How long a wrong value stands before the source replaces it.

Completeness by segment

What share of the expected records or fields are actually present, broken out by a segment the source defines. Ninety-nine percent nationally can still be sixty percent in the one state you care about.

Schema stability

How often fields are renamed, retyped, or moved without notice. This is the dimension that breaks integrations at three in the morning.

Internal consistency

Whether a single response contradicts itself: totals that do not sum, ranges inverted, timestamps ordered backwards.

Two rules that survive the handover

Accuracy is never published without naming its anchor. An accuracy number means nothing unless you can see what it was graded against, so any card carrying one names the independent, settleable reference on the same page. Most sources have no such anchor and therefore carry no accuracy figure at all.

A missing measurement is never rendered as a zero. A dimension without enough samples reads insufficient data. Zero is a measurement; this is the absence of one, and collapsing the two is how benchmarks start lying.

Who pays for the grading

Trooth funds Modafied. Hiding that would be worse than the arrangement itself, so here is the number: $25 a month, which is half of the $50 monthly cap across both properties, for the compute behind the public scorecards.

Three things about that payment matter more than its size. It is fixed, so it does not move with a score, a grade, or a ranking. It is published, on this page, which means changing it is a visible act rather than a private renegotiation. And it buys compute, not conclusions: Modafied takes no revenue from any party it grades, including this one, so no source, provider, or feed can pay to be measured or pay to be measured well.

A funder whose payment varies with the grade is buying the grade. That is the failure this structure is built to avoid, and a reader is entitled to check the structure rather than trust the intention. The check is that Modafied's scoring code and method are open and its scorecards are meant to reproduce byte for byte from the snapshot they name, so a second party can run the same code on the same data and compare. Independent replicas doing exactly that are planned rather than running today.

Trooth's own MCP server will be graded at Modafied by the same code once it exists. Being the funder does not exempt it.
