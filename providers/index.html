Phase 3 Marketplace

List Your Feed in the Agent Data Pipe

Data owners, custom filter authors, and analysis creators: sell your feeds directly to agent swarms without building custom MCP servers or handling billing.

Why Selling Data to Agents is Broken Today

Integration Friction

Every agent developer must write custom connectors, configure per-user credentials, and manage authentication stores.

Context Window Bloat

Publishing your own standalone MCP server forces users to burn context window tokens just to register your tool definitions.

Trust & Quality Doubts

Buyers have no independent way to verify your latency, uptime, or revision behavior before subscribing.

What Trooth Does for Providers

1. Zero Integration Overhead

You list once as a catalog YAML entry. Any agent connected to Trooth can immediately resolve queries to your endpoint without installing new tools.

2. You Set Your Own Price

Providers set their own price per query or per record. Trooth does not price your data. We handle per-request metering and automated payouts.

3. Public Scorecard Included

Every listed feed gets the same objective six-dimension scorecard as public sources. Superior freshness and schema stability immediately differentiate your feed. We do not run that scoring ourselves. Modafied does, and its emblems are shown below exactly as they come.

4. Cryptographic Provenance & Lineage

Your responses are signed with Ed25519 envelopes and hashed with SHA-256. Consumers get verifiable audit trails proving the data came from you.

What the Benchmark Actually Says

These are the live Modafied emblems for the feeds we route to today. They are hotlinked from Modafied, not copied here, so they show the current measurement and they change without asking us. Every one carries a trace id: click it and you get the exact scorecard digest, method version, and band table the grade came from, plus every claim that emblem has made before.

Disclosure, because it matters here

Trooth funds Modafied. That is exactly why this section shows every feed we route to rather than the flattering ones: below you will find a C, and two feeds we cannot yet measure well enough to grade at all. Modafied runs identical code on every source, takes no money from anything it scores, publishes no purchasable emblem of any kind, and will score Trooth's own MCP server the same way once it exists. An emblem here is a measurement with a date on it, not an endorsement, a certification, or a partnership. If a grade falls, the emblem on this page falls with it and we get no notice.

A feed reading insufficient data has not been withheld or hidden; it means the benchmark does not yet have the samples to grade it, and saying so is the point. Method and band table: the published method. Resolve any trace id: the trace resolver.

How to Submit a Feed

Feeds are submitted via open pull requests to the Trooth catalog directory conforming to schema/catalog/v0.1.json: 

# Example Provider Entry: catalog/sources/custom-finance.yaml
id: "custom-finance"
name: "Acme Real-Time FX"
description: "Sub-second foreign exchange spot rates with settlement guarantees."
endpoints:
  - name: "latest_rates"
    url: "https://api.acme.example/v1/rates"
    method: "GET"
auth:
  type: "bearer"
license:
  spdx: "Commercial"
  url: "https://acme.example/terms"
  redistribution_allowed: true
refresh_cadence: "10s"
declared_lineage:
  role: "primary"
freshness_field: "timestamp"
cost:
  model: "metered"
  rate_limit: "600 requests per minute"
